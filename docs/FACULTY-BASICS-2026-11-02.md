## 查找、筛选与来源

Faculty directory 的学校、职称、研究和博士训练使用独立列。修复整张表挤在两栏网格左半边的问题；提供全宽表格、紧凑卡片和完整个人档案。原始研究与细分分类分别显示。学校页补充职称、单位及研究覆盖，并可进入该校有研究原文的人员。

任职证据筛选区分已记录、历史、访问、荣休、未来与待核对；已记录不等同于实时全员确认。缺口与已有字段指标均可点击筛选，URL 保留状态。CSV / JSON 导出保留原始证据、真实抓取日期、字段复核、单位层级、任职待核验说明和未知值；加载证据失败可重试。

## 来源检查与可复现数据

本轮对缺基础字段的 1,173 个既有档案登记主页进行一次有限并发读取：976 个得到非空文本供筛选、20 个空正文、133 个访问失败、44 个没有登记个人主页。HTTP 成功不等于事实确认，非空正文也可能只有模板；仅选中的字段进入发布批次，其余保持待核验。

主要读取日为 **2026-11-01**，泉州独立来源于 **2026-11-02** 读取；人工整理／导入日期为 2026-11-02。旧引文迁移仍保留原核验日期。来源哈希、URL、状态、字段选择和错误原因见 [source pass](../data/research-updates/2026-11-02-faculty-basic-source-pass.json)。未确认字段及具体人员见 [计算审计](../data/faculty-basics-audit-2026-11-02.json)。某网页未被选出证据不代表公开资料一定不存在。

导入使用不可变批次 ID、前置数据哈希、明确旧人员 ID 与身份依据；[回执](../data/faculty-basics-receipt-2026-11-02.json)保留逐人 before 和 after 哈希。修复相同 URL、引文、标签的多个字段证据被最后一条覆盖的问题，现在合并 supports。旧报告的断言使用回滚后历史快照，不把旧版缺口改成新版数字。

```sh
node scripts/import-faculty-batch.mjs data/research-updates/2026-11-02-faculty-basics-reviewed.json
node scripts/sync-data.mjs
node scripts/faculty-basics-report.mjs
node scripts/check-faculty-extensions.mjs
node --test scripts/tests/*.test.mjs tests/*.test.mjs
```

重复导入相同批次无变化，修改已用 ID 或过期输入会被拦截。历史 HTML/PDF 是本地核验缓存，不在构建时重抓；发布的精简证据与哈希、原始链接、Git 版本用于追溯。
