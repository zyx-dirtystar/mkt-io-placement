# Marketing PhD job market：参考项目、官方资料与本版修订

核查日期：2026-11-17。目标覆盖 Quant / Modeling、Consumer Behavior、Marketing Strategy，优先把 Quant 的培养端、求职者、招聘端和初始去向联系起来。本文与资源目录是一次有边界的研究，不代表已完成全球市场普查。

## 结论

已有可借鉴项目，也有学会和学校官方资料，但它们解决的问题不同。本轮检索未找到一个同时完整覆盖全球 Marketing 三方向、历年全体毕业生、当季候选人、广告与实际聘用的统一官方数据库。这是本轮检索结果，不是证明这种数据库不存在。

当前项目已有较好的证据结构：区分来源名单年、毕业年、求职季和首职年；保留未知 tenure、最终安排与首职回退；将 faculty 与 placement 分开。主要短板是覆盖范围和可用于比较的分母，不能靠继续增加在职教师数量解决。

## 最值得参照的项目与资料

| 来源 | 能回答什么 | 本项目应借鉴什么 | 不能怎样使用 |
| --- | --- | --- | --- |
| [AMA DocSIG — Who Went Where](https://docsig.org/who-went-where-report/) | Marketing 博士求职经历及自愿报告的 placement；页面列出 2025 报告与往年档案 | 每个年度保留调查对象、题目和有效回答数；把外部基准与人物记录分开 | 自愿填答不是全体毕业生普查；2025 的地域限制与题目调整影响跨年可比性 |
| [Econ PhD Placements](https://www.econphdplacements.com/) | 经济学博士初始去向、学校比较、雇主和年度覆盖 | 覆盖矩阵、原始 placement 文本、首职浏览、可下载数据、同校趋势 | 独立研究项目，并非学会官方统计；其部分仅有雇主的学术记录会推断 TT，本项目应保留更保守的未知规则 |
| [Ron Berman — 2026 Marketing 市场分析](https://www.linkedin.com/pulse/insights-marketing-academic-job-market-2026-ron-berman-05hoe) | 招聘公告、学校数和流程变化的有日期观察 | 按同一季节截点、相同平台与去重方式看趋势 | 教师个人分析不是官方普查；2026-06-19 附近的截点和预测不能当作全年实际聘用人数 |
| [AMA Academic Job Board](https://academicplacement.ama.org/) / [ELMAR 招聘档案](https://www.ama.org/listing-types/jobs/) / [AMS Job Board](https://amsweb.mcjobboard.net/jobs) | Marketing 三方向的职位发现 | 保留原雇主链接、岗位编号、原始日期与跨平台别名 | 广告数不等于岗位数；重复发布、常年征集、历史页面须区分。AMA board 正文此次访问受限 |
| [EconJobMarket](https://econjobmarket.org/positions) / [AEA JOE](https://www.aeaweb.org/joe/listings) | Quant / IO 交叉岗位的重要补充渠道 | 实际院系、研究要求、申请截止与优先审阅日期分别保存 | Economics IO 不自动归为 Quant Marketing；本轮没有批量复制 JOE 列表 |
| [AEA EconTrack](https://www.aeaweb.org/econtrack) | 自愿报告的雇主招聘阶段 | 将广告、初面、flyout、offer、filled 等阶段独立记录，并保留来源身份 | 不是全部雇主或个人 offer 的实时追踪 |

历史上的 [MarketingPhdJobs.org](https://marketingphdjobs.org/) 在此次访问时转到 AMS Job Board，作为同一入口的别名，不重复计作两个独立岗位数据库。[EMAC Job Market](https://www.emac.academy/job-market/) 此次可读页面显示的是明确标注的虚构 DEMO 岗位，故只借鉴其筛选设计，不导入招聘数据。

CB 另有 [ACR listserv](https://acrwebsite.org/resources/listserv/) 与 [SCP jobs](https://myscp.org/current-jobs/)；后者此次正文提取只得到嵌入占位，不等于没有职位。[EMAC job-market training](https://www.emac.academy/emac-job-market-training/) 可作为求职准备入口。[AMA 2022 指南](https://www.ama.org/2022/04/02/guidelines-marketing-academic-job-market/) 与 [AEA 2026 指南](https://www.aeaweb.org/news/guidance-job-market-sept-9-2026) 必须标注学科和年度，不能把旧 Marketing 建议或 Economics 日程套成整个 2026–27 Marketing 市场的硬性时间表。

## 当前数据库的具体缺口

以下由 `node scripts/check-market-resources.mjs` 从本地权威数据生成，详见 `data/market-reference-audit-2026-11-17.json`：

| 指标 | 当前数量 | 含义 |
| --- | ---: | --- |
| Placement 档案 | 308 | 含已知去向、当季及待核验档案，并非 308 个已完成就业结果 |
| Faculty 档案 | 1,358 | 独立接收端人群，不能加入博士 cohort 分母 |
| 2026–27 求职季档案 | 17 | 只代表已收录，不代表当季人数 |
| 已确认完整 cohort | 0 | 暂不能据此估计全市场就业率或项目成功率 |
| Quant / CB / Strategy 已标注人数 | 74 / 64 / 3 | 标签可交叉；差异首先提示采集与分类缺口 |
| Marketing 尚未细分方向 | 140 / 281 | 不应把未知方向强行分入 Quant 或 CB |
| 招聘广告 | 18 | 本轮前为 16；含历史和未知状态，不是当前开放岗位总数 |

当前固定 Marketing 培养范围仍是北美 50、香港 5、新加坡 3，共 58 个项目发现目标。澳大利亚和澳门的 faculty 扩展发生在接收端，不会自动扩展培养项目分母。欧洲培养端需要独立、可复现的扩展规则；全球接收机构存在也不等于全球博士项目已覆盖。

## 本轮已经落地的修改

1. 新增 `#resources` 页面，首页与导航均有入口。31 条参考资料可按 Quant、CB、Strategy、IO、求职问题和来源类型筛选；各条保留版本、复核日期、用途、限制及可借鉴做法。24 条读到正文、5 条访问或提取受限、1 条跳转、1 条 DEMO；访问尝试不写成已读。
2. 将 [DocSIG 2025 报告](https://docsig.org/wp-content/uploads/2025/09/2025-AMA-DocSIG-WWW-report.pdf) p.10 Table 3 的过程指标作为独立外部基准：总回答者 61；申请均值 69.9（n=59）、初面 13.1（n=59）、offers 1.9（n=57）。对象是北美博士来源和／或北美聘用机构相关的自愿填答者，不是 Quant 专属目标、个人预测或市场成功率。匿名调查与另外自愿提供的姓名 placement 不作个体连接。
3. 招聘界面区分最终申请截止、优先／full-consideration 日期、广告结束日与已核验的招聘阶段。浏览当天 UTC 日期只用于判断明确的日级截止是否已过，不会刷新来源核验日期或个人职业观察窗口。同日仍保留；未给时区时不虚构精确截止时刻。优先日期已过不会自动关闭；单纯广告到期只降为待核验。
4. 重新读取 [UBC EJM 12709](https://econjobmarket.org/positions/12709)、[Cornell EJM 12658](https://econjobmarket.org/positions/12658)、[CUHK-Shenzhen EJM 12463](https://econjobmarket.org/positions/12463) 和 [UIB EJM 12847](https://econjobmarket.org/positions/12847)。前三条 EJM 申请通道已关闭而处于 reviewing 阶段；保留正文中 rolling／late-review 的差异，不推断已聘用。UIB 的明确截止仍为 2026-12-05。
5. 增加两条有雇主原文的 Quant 示例：[Calgary](https://careers.ucalgary.ca/jobs/18360463-associate-professor-marketing) 实际正文是 Assistant Professor，申请截止 2026-11-18；[Frankfurt School](https://www.frankfurt-school.de/en/about/careers/assistant-professor-of-marketing) 明确 Quant/Strategy，但最终提交日 2026-07-15 已过，作为历史广告，招聘季与入职日未公布则保留未知。没有凭 URL 中的 associate-professor 或教学兴趣推断职级与研究方向。
6. 版本日期更新为 2026-11-17，人物事实观察截止仍是 2026-11-02；人物、首职与完整 cohort 均未因新增入口自动更新。数据更新报告同时标注两个日期，招聘导出保留判断日期与原核验日期。

职位改动前值、后值和新增记录保存在 `data/research-updates/2026-11-17-jobs-reviewed.json`。这是人工复核收据，不是可交给现有人物批次导入器的文件。完整入口、地域与阅读限制见 `data/market-resources.json`。

## 下一轮补全标准：Quant 优先，但三方向采用同一规则

| 优先级 | 具体工作 | 完成标准 |
| --- | --- | --- |
| P0 | 建立培养项目 × 年份的候选人／毕业生名册；先做 Quant 密集项目，再以同一规则覆盖 CB、Strategy | 每格区分“学校名单已对齐”和“整届人数已证实”；未知去向仍留在名册；2023–26 历史与 2026–27 当季分开 |
| P0 | 核验 Quant 的 research identity、JMP、methods 与初始安排 | 标签有本人或系所明确依据；empirical / analytical / methods 分维保存；IO、AI/ML 或一篇论文主题不能单独确立 Quant Marketing 身份 |
| P1 | 为欧洲等缺口建立版本化培养范围，优先核查 LBS、INSEAD、Tilburg 等发现入口 | 先确认项目资格及范围，再采人；新地区与旧 58 项目的可比口径明确，避免按成功案例倒选学校 |
| P1 | 以学校招聘原文维护三方向需求清单，Quant 同查 EJM / JOE | 同一 search 跨平台去重；rank、方向、招聘季、deadline、状态、人数、核查日分别记录；只含明确已核验的状态 |
| P1 | 补查 140 位未细分 Marketing 与 Strategy 的薄弱覆盖 | 有证据才分类；允许交叉和未知；Marketing Strategy 不等同于所有 Management/Strategy 学者 |
| P2 | 在可比 cohort、时间轴与来源窗口具备后增加趋势比较 | 展示分母、未核验与缺失；未满足前不发布市场份额、学校就业率或个人录用概率 |

“最全面”应以这些可检查的覆盖单元定义，而不是以累计链接、人物或 faculty 数量定义。

## 验证与交付边界

仓库既有数据、placement、evidence、faculty 与 observatory 检查通过，79 项测试全部通过，包含新增的招聘日期语义、来源筛选和输出转义测试。资源一致性检查确认注册表随 `sync-data.mjs` 进入完整与运行时 catalog，独立的 survey 不进入人物统计。修改过的 JavaScript 通过语法检查；本地执行日志为 `reports/validation-2026-11-17.log`（日志不提交）。

本轮浏览器视觉验收未完成：内置浏览器无法连接本地预览；Windows Chrome 操作工具随后因无法可靠识别当前 URL 而中止。不能将以往 UI guide 中的视觉验收记录当成本版验收。代码和数据验证结果以本次执行日志为准，发布前仍应打开 `#resources` 与 `#jobs` 检查桌面及手机布局。
