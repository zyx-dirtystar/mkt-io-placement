# 分阶段完善网站

2026-10-08 范围修订：用户要求 Marketing 全方向纳入，包括 Quantitative Marketing、Consumer Behavior 和其他 Marketing 方向。收集单位为目标地区的博士年度名单，不限于能明确分类为 Quant 的候选人。研究方向作为后续筛选标签；Economics IO 部分继续保留。此修订是下一阶段目标，现有 51 人的数据集尚未完成扩充。

## 当前缺口

当前是来源可追溯的首批样本，不是四地区的院校或候选人全集。初版先收集能核验的人员，再整理院校，因此没有形成完整的院校与年度分母，遗漏不能解释为没有相关毕业生。

后续改为先建目标院校和项目清单，再逐年核验完整 cohort。收集对象包括尚未找到去向的候选人，不能只收录成功任职者。

## 阶段 1：交到自己的 GitHub

交付：自己拥有的源代码仓库、确认公开范围后的可访问网站、一次数据更新演示。

已准备：自动检查与发布的工作流、中文操作说明。

待完成：账号与目标仓库确认、连接、上传、Pages 设置、线上验收。当前不能视为部署完成。

## 阶段 2：建立目标院校与覆盖矩阵

范围：美国、加拿大、香港、新加坡的 Marketing 博士项目及 Economics IO；全球就业去向。Marketing 与 Economics 分开核验，即使属于同一学校。Marketing 先收完整候选人或毕业生名单，再标注 Quant、CB、其他或待确认；不因方向不清而排除 Marketing 项目人员。Economics 仍依据公开资料识别 IO。

先记录用户指出的缺失学校，再系统扩展四地区清单，不把用户记得的学校当作全集。

每个核验单元包含：学校、项目、领域、年份或求职季、官方 cohort 来源、核验进度、符合领域人数、已录入人数、去向未确认人数、缺口说明和核验日期。历史 placement 年与求职季分别保存，不自动互换。

状态至少区分：未开始、名单已找到、核验中、名单核验完成、官方尚未发布、资料不足。核验完成须说明依据和完整性限制；去向未知不阻止候选人入库。只有名单与领域筛选均已核验，才能将相关人数记为 0；未查到用未知。

交付：按地区和项目分组的目标清单、网站覆盖页面的进度表。院校全集建立后也需持续核查项目增设或停招。

## 阶段 3：分批补齐人员与去向

每批选择 3–5 所学校，覆盖历史 2023–2026 首职档案和 2026–27 当季。先整理官方完整候选人/毕业生名单；Marketing 全方向纳入，Economics 依据公开资料筛选 IO；最后追踪首份岗位，后来任职单独记录。已有记录的学校也重新检查整届名单，不能默认它们已经查全。

每批交付：新增/修订人员、相关 cohort 的核验情况、仍缺的信息和来源。暂不根据学校声誉或手头易得程度决定总体覆盖范围。

比较展示同时报告样本数和覆盖缺口；在没有完整候选人分母前，不报告市场就业率。中国公民或华裔身份仅采用明确公开依据，不根据姓名猜测。本科教育地区是独立变量。

## 阶段 4：逐年维护

保留稳定人员 ID、原始来源、核验日期和修订记录；每年新增求职季，滚动展示最近四年，同时保留历史档案。维护流程是“新增名单 → 核验 → 补去向 → 检查 → 发布”。

交付：可重复使用的年度清单与一次完整更新演示。自动搜集或定期检查属于后续功能，目前尚未启用。
